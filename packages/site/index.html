alerts

One stream of alerts from many sources (weather, news, service status and more), with dedup, ranking and delivery that survives faults.

The demo below runs the real code of the system in your browser. The messages, the places and the people are made up. The page calls no server.

    How it works

    1. Map. A source adapter turns each message into a report, in one format for each source.
    2. Merge. The core joins the reports of one event: by a reference, by a shared key (VTEC) or by a link rule.
    3. Assess. The policy gives each person a level for each incident, with the reasons.
    4. Deliver. The channels send the level, and escalate until the person acknowledges a life-safety message.
